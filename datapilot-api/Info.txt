### DataPilot flow
POST /api/v1/datasets
        ↓
DatasetController
        ↓
DatasetService
        ↓
DatasetRepository
        ↓
PostgreSQL
Controller handles HTTP → Service handles business logic → Repository handles persistence.

##################### For DataPilot:

                      PostgreSQL


Postgres Installation and Startup steps:
  1. winget search PostgreSQL
  2. winget install --id PostgreSQL.PostgreSQL.18 --source winget       or winget search postgres
  3. psql --version
  4. Start-Service postgresql-x64-*
       If PowerShell doesn't accept the wildcard for Start-Service, first run:
       Get-Service *postgres*
       from output update this and run: Start-Service postgresql-x64-17
  5. psql -U postgres
  to vreify: psql -U postgres -h localhost -p 5432
           pass: postgres
  6. "list databases": \l
  7. If datapilot exists, connect to it:

     \c datapilot

     else
     CREATE DATABASE datapilot;
        Then connect
  8. \dt
        List tables . Hibernate should create the datasets table when we start DataPilot.

        PostgreSQL
            ↓
        CREATE DATABASE datapilot
            ↓
        Spring Boot connects to datapilot
            ↓
        Hibernate sees @Entity Dataset
            ↓
        Hibernate creates datasets table
            ↓
        POST /api/v1/datasets
            ↓
        DatasetRepository.save()
